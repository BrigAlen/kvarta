## Решения по ходу (кроме записанных в `NOTES.md` и `docs/design.md`)

- Появление секций на `IntersectionObserver`, а не на CSS scroll-driven animations: MDN помечает их «Limited availability».
- Одно соединение с базой на запрос и одна повторная попытка только на этапе подключения (запись повторять нельзя).
- Дедупликацию контролировали экспериментом без замка (10 дублей), см. `docs/storage.md`.
- Данные об источнике хранятся в sessionStorage, не в cookie и не в localStorage.
- Две залитые кнопки рядом спорили бы друг с другом: в подписке кнопка контурная.
