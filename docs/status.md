# Статус работы без пользователя

Это журнал автономной сессии: что сделано, что проверено, что спорно, что осталось. Дополняется по ходу работы.

**Правила сессии (от пользователя):** планов не ждать; коммитить по ходу, **не пушить** (прод остаётся как есть); прод-базу не трогать; миграции только на `dev`; `ALTER TABLE` для production отдельным файлом, пользователь применяет сам.

**Порядок:** 5а-2 (доработка дизайна), затем шаг 5 локально по критериям из `steps.md`.

## Решения по ходу

### 5а-2 (доработка дизайна)
- **Плавное появление на IntersectionObserver, а не на CSS scroll-driven animations.** MDN помечает `animation-timeline: view()` как «Limited availability» (нет в некоторых широко используемых браузерах), а на телефоне пользователя эффект должен быть виден. Маленький клиентский компонент `RevealOnScroll`: прячет только то, что ещё ниже экрана (вспышки нет), без JS всё видно, при prefers-reduced-motion не включается. Первый экран не анимируется (LCP).
- **Шапка:** всегда полупрозрачный фон с размытием (на верху страницы сливается с фоном), запасной сплошной фон без поддержки backdrop-filter. Якоря сдвинуты на 4.5rem (scroll-margin).
- **Главные кнопки залиты брусникой** (белый текст 7.45:1; на тёмном светлый акцент и тёмный текст 6.9:1), в первом экране и в форме. Кнопка в подписке осталась контурной (вторичная): две залитые рядом спорили бы друг с другом.
- **Скругления 0.75rem у кнопок и полей, 1–1.25rem у фото:** ответ на «всё с жёсткими краями».
- **Переходы свет/тёмный** градиентом по краю секции (с мягкими стопами, чтобы середина не была серой кашей), фото в подписке растворяется маской вниз, фото в форме и на первом экране по нижнему краю. Градиенты только как переходы, по новому правилу CLAUDE.md.
- **Подчёркивание в заголовке «проезжает»:** линия рисуется фоном (не text-decoration), сначала под «четверг», потом под «пятницу»; при reduced-motion сразу целиком.

## Спорное, оставлено на утро

- **Серая полоса перед светлой секцией после подписки.** Градиент тёмный→светлый всё ещё читается как полоса на 1440 px. Если не нравится: короче переход или жёсткая граница обратно. Реальный телефон я не видел, размытие шапки проверено только эмуляцией Chrome.
