# Лендинг обжарки «Кварта» — тестовое задание

ТЗ: https://tz.vitai.world/ (бриф клиента продублирован в `.claude/skills/kvarta-step/references/brief.md`).
Дедлайн: понедельник 19.10, 18:00 МСК.

## Стек и инфраструктура
- Next.js (App Router) + TypeScript.
- Хостинг: Render, free web service (Node, `next start`). Локальная файловая система эфемерна: данные в ней не хранятся. Free-сервис засыпает после 15 минут без входящих запросов, лимит бесплатных часов общий на workspace.
- База: Neon Postgres, создана напрямую в консоли Neon (без интеграций). Прод Render использует строку ветки `production`, `.env.local` — строку ветки `dev`. Регион сервиса и базы — Франкфурт.
- Секреты только через переменные окружения, в репозитории — `.env.example`.

## Как работаем
- Работа идёт по шагам из `references/steps.md`. Для любого шага используй скилл `kvarta-step`.
- Перед кодом — план шага, потом жди моего подтверждения.
- Один шаг = один или несколько осмысленных коммитов. Сообщения на русском, в повелительном наклонении: «Добавить форму заявки».
- После изменений `npm run build` и `npm run lint` должны проходить.
- Не добавляй зависимость, не объяснив, зачем она и можно ли без неё.
- Если не уверен в поведении API, библиотеки или хостинга — скажи прямо и предложи, как проверить. Не угадывай: твои знания о версиях Next.js могут быть устаревшими.

## Дизайн и тексты
- Аудитория 25–45 лет, в основном с телефона, из рекламы в Instagram и Яндексе. Mobile-first.
- Тон: тёплый и простой, как бариста говорит с гостем. Без пафоса и «премиального глянца».
- Сайт должен выглядеть как работа студии для этого конкретного клиента. Не используй: градиентные фоны, glassmorphism, эмодзи вместо иконок, сетку «три карточки с иконками», абстрактные заголовки в духе «Откройте мир кофе».
