# Как проверять

Проверка — это доказательство: вывод команды, ответ сервера, запись в БД. Если проверить из терминала нельзя, попроси пользователя и скажи, на что смотреть.

## Телефон
Ожидаемо принимаются (и приводятся к одному виду):
- `+375 29 123-45-67`
- `+375291234567`
- `375291234567`
- `80291234567`
- `8 029 123 45 67`
- `+375 (44) 123 45 67`
- коды 25, 33, 44 в тех же форматах

Ожидаемо отклоняются:
- `+375 19 123-45-67` — нет такого кода
- `+375 29 123-45-6` — не хватает цифры
- `+375 29 123-45-678` — лишняя цифра
- `+7 912 345-67-89` — не Беларусь
- пустая строка, буквы

Спорные, решение записать как допущение в README:
- городские номера (`+375 17 …` и другие коды областей) — принимаем или нет;
- номер без восьмёрки, начинающийся с `0` (`029 123 45 67`).

## Дедупликация
Проверяй на запущенном сервере. Один и тот же номер:
1. Две последовательные отправки → одна запись.
2. Два одновременных запроса, например:
   ```bash
   for i in 1 2; do curl -s -X POST "$URL/api/lead" -H 'Content-Type: application/json' -d "$BODY" & done; wait
   ```
   → одна запись в БД. Покажи результат запроса к таблице.
3. Тот же номер, записанный в другом формате (`80291234567` после `+375291234567`) → тоже дубль.
4. Через 10 минут (или с временно уменьшенным окном для теста) → новая запись создаётся.

## Источник рекламы
1. Открыть сайт с `?utm_source=instagram&utm_medium=cpc&utm_campaign=autumn&utm_content=ad_3&fbclid=test123`.
2. Перейти по якорям, обновить страницу без параметров.
3. Отправить форму.
4. В записи БД есть все метки, реферер, страница входа и страница отправки.
Повторить с `yclid` для Яндекса.

## Ошибки
- Заблокировать сеть в DevTools и отправить форму → понятное сообщение, данные на месте.
- Эмулировать ответ 500 (например, временно испортить `DATABASE_URL` локально) → понятное сообщение.
- Отправить невалидный JSON и невалидные поля напрямую curl'ом → сервер отвечает 400, не 500.

## Telegram
- Заявка приходит в чат с данными и источником.
- С неверным токеном заявка всё равно сохраняется, пользователь получает успех без задержки.

## Превью ссылки
- Отправить ссылку в Telegram самому себе, убедиться, что видны картинка, заголовок, описание.
- Абсолютные URL у `og:image`.
